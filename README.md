# 🏢 Central de Certidões Negativas para o Setor Imobiliário de Minas Gerais

Este é um site estático projetado para ajudar despachantes imobiliários, corretores, proprietários, compradores e inquilinos envolvidos em negócios de imóveis. A página funciona como uma central de links rápidos, reunindo botões que direcionam o usuário de forma direta e segura para os portais oficiais de emissão das **Certidões Negativas** necessárias na compra, venda ou locação de um imóvel.

O objetivo principal é acelerar a checagem de documentos e garantir a segurança jurídica dos negócios, eliminando a perda de tempo com buscas demoradas na internet.

## 🚀 Funcionalidades
* **Foco Imobiliário:** Agrupamento das certidões essenciais para fechar negócios imobiliários sem riscos.
* **Links Diretos:** Acesso em um clique à página exata de emissão de cada órgão, evitando caminhos confusos em sites do governo.
* **Interface Limpa:** Design simples focado em rapidez, facilidade de uso e objetividade.
* **Design Responsivo:** Funciona perfeitamente em computadores, tablets e celulares.

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido como um site estático leve, garantindo carregamento instantâneo:
* **HTML5:** Estruturação da página e dos links de redirecionamento.
* **CSS3:** Estilização visual, layout e visual dos botões.
* **JavaScript:** Pequenas interações e melhorias para o usuário.
